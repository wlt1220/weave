Let me show you the merge engine. Three scenarios, one file. Scenario one: two agents edit different functions — one adds an idempotency key to charge, another adds an audit trail to refund. Weave computes their causal cones — the functions each change can affect. The cones don't intersect, so both merge lock-free, in under a millisecond. No branches, no pull request, no waiting. Scenario two: two agents edit the same function. The cones overlap, so Weave opens a negotiation. Both agents state their case. The arbiter checks verification: exactly one intent has passing tests — it wins, and the loser's change is preserved as a ghost, not deleted, ready for follow-up. Scenario three: one agent changes the log function, another changes refund — which calls log. The dependency cone overlaps. Both are verified, so there's no safe automatic call. Weave escalates to a human — with both intents, both rationales, and the full affected cone attached. Every outcome is recorded. Nothing is silently dropped.
