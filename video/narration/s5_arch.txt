Now the coordination plane, on Cloudflare. Agents submit intents to Workers — each intent is validated and sealed by content hash. Every stream gets its own Durable Object, which owns the log, the trunk, and negotiations — strong ordering exactly where merge order matters, nowhere else. And every stream is backed by a Cloudflare Artifacts repo: intents are mirrored as versioned files, reachable over git over HTTPS. So the git bridge is free — any git client can clone a stream's history.
