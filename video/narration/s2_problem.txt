Git was built in two thousand five, for humans mailing patches. It worked beautifully — for us. But agents don't mail patches. They write code at machine speed — hundreds of thousands of them, editing the same repository, at the same time. Branches become noise. Pull requests become a traffic jam. Merge conflicts become a full-time job. We don't need a faster Git. We need to rethink what version control even is, when the authors aren't human.
